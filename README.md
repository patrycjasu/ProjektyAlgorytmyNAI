# ProjektyAlgorytmyNAI

Projekty prostej implementacji poszczególnych algorytmów w ramach przedmiotu Narzędzia sztucznej inteligencji, wykonane podczas 4 semestru. Wszystkie implementacje są w Javie.

## Algorytmy i Projekty:

- k-NN: dokonanie klasyfikacji metodą K najbliższych sąsiadów wszystkich obserwacji zbioru testowego, bazując na zbiorze treningowym. Zwraca dokładność klasyfikacji.
- Perceptron: stworzenie modelu perceptronu i wytrenowanie go pod kątem dwóch gatunków kwiatów, ze zbioru treningowego i testowego; wypisanie dokładności klasyfikacji.
- Sieć jednowarstwowa: stworzenie sieci jednowarstwowej bazującej na poprzednim projekcie perceptronu; wykorzystanie do identyfikacji języka tekstu wejściowego, poprzez zliczanie częstotliwości występowania alfabetu łacińskiego.
- Problem plecakowy: implementacja metody brute-force dla problemu plecakowego.
- Problem plecakowy hill climbing: zastosowanie metody wspinaczkowej dla problemu plecakowego.
